.txt · .csv · .zip (PC·Android·iPhone·Mac 내보내기 지원)

🔒서버 전송 없음. 파일은 이 브라우저 메모리 안에서만 읽고 분석합니다. 페이지를 닫으면 사라지며 어디에도 저장되지 않습니다.

대화 내보내기 방법

PC (Windows)

  1. 채팅방 열기
  2. 우측 상단 ≡ 메뉴
  3. 대화 내용 → 대화 내보내기
  4. .txt로 저장 후 업로드

Android

  1. 채팅방 ≡ → 우측 상단 ⚙ 설정
  2. 대화 내용 내보내기
  3. 텍스트만 보내기
  4. 내 기기/드라이브에 저장 후 업로드

iPhone

  1. 채팅방 ≡ → 우측 상단 ⚙ 설정
  2. 대화 내용 내보내기
  3. 텍스트 메시지만 보내기
  4. 파일 앱에 저장 후 업로드
.zip으로 받았다면 그대로 올려도 됩니다.

Mac

  1. 채팅방 열기
  2. 메뉴 → 대화 내보내기
  3. CSV 파일로 저장
  4. .csv 업로드
메뉴 위치는 앱 버전에 따라 조금씩 다릅니다.
