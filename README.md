# 단톡 Recap

카카오톡 대화 내보내기 파일(.txt/.csv/.zip)을 브라우저 안에서만 분석해 연말 결산 카드 8장을 만드는 단일 HTML 앱.

- 실행: `index.html`을 브라우저로 열면 끝 (빌드·서버 불필요, 정적 호스팅 가능)
- 외부 의존성: html2canvas 1.4.1(카드 → PNG), JSZip 3.10.1(zip 해제), Google Fonts
- 개인정보: 파일은 FileReader로 메모리에서만 처리, 네트워크 전송·저장 없음

## 지원 형식
| 형식 | 메시지 줄 예시 |
|---|---|
| PC(Windows) | `--- 2026년 1월 3일 토요일 ---` 다음 `[홍길동] [오후 3:05] 메시지` |
| Android | `2026년 1월 3일 오후 3:05, 홍길동 : 메시지` |
| iPhone | `2026. 1. 3. 오후 3:05, 홍길동 : 메시지` (24시간제도 지원) |
| Mac | CSV `Date,User,Message` |

인코딩은 UTF-8/UTF-16(BOM)/EUC-KR 자동 감지. 여러 줄 메시지는 직전 메시지에 이어 붙이고, 입장·퇴장 등 시스템 메시지는 제외.

## 지표 정의
- 수다왕: 메시지 수
- 읽씹왕: 1시간 공백으로 대화 세션 분리 → 2명 이상·5개 이상 오간 세션 중 불참 비율(메시지 20개 이상 멤버, 세션 8개 이상)
- 올해의 단어: 링크·자모(ㅋㅎ)·이모지·조사·불용어 제거 후 빈도 / 입버릇은 개인 빈도 ÷ 전체 빈도
- 새벽 3시 출몰: 02:00–04:59 메시지 수, 출몰한 밤 수, 3시대 메시지 수
- 웃음 제조기: ㅋㅋ·😂 메시지 → 5분 내 직전 '다른 사람'의 메시지에 반응 1회(반응자×메시지 중복 제거)

## GitHub Pages로 배포하기
1. 이 폴더의 `index.html`, `README.md`를 새 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/`에서 열립니다. 이 주소에서는 "이미지로 저장" 버튼이 PNG를 바로 내려받습니다.
